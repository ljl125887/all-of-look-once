# 实例检索评估协议

分别评估“检测到对象”和“判断为同一实例”，避免用类别检测准确率代替实例匹配准确率。

1. 登记参考集：允许单图和多图两种条件，记录清晰度、视角和目标像素尺寸。
2. 建立独立查询集：与参考集分开，逐段标注目标出现/离开时间及框位置。
3. 加入困难负样本：同色同车型、相同服装、反射、画面边缘、遮挡和低照度。
4. 用验证集校准阈值，再在未参与调参的测试集计算指标。
5. 先离线回放，再使用正式实时流程验证断流重连、跨流确认和证据录像。

建议报告：检测召回率、实例匹配 precision/recall、每小时误报警数、漏检事件数、重复报警率、ID切换次数、首次报警延迟、端到端画面时延、CPU/GPU/显存占用。

每个已知目标至少覆盖完整进入、离开重入、短时遮挡、多人交叉与跨流出现。系统默认多帧确认以及同路离开计时会影响事件边界，应分别记录人工时间与系统时间。

阈值和最小人体/人脸尺寸是实现默认值，不构成通用准确率承诺。公开评估时记录模型版本、采样率、分辨率、硬件和误差定义，证据不足的样本进入人工复核。
