# 公开文件边界

发布包通过白名单建立，采用独立Git历史。

公开：核心Python源码、空配置、依赖列表、架构与使用文档、模型来源说明、无模型单元测试、脱敏扫描脚本和CI配置。

排除：现场视频/图片、人物参考图/特征、目标库、摄像头配置、账号口令、内网地址、运行日志、事件录像、验收报告、模型权重、GPS/航线/地理信息文件及原目录Git历史。

检查命令：

```bash
python tools/check_public_release.py
python -m unittest discover -s tests -v
```

扫描覆盖常见凭据格式、私人地址、绝对路径、媒体和地理文件。发布前仍需人工核对新增文件的语义；`.gitignore`不能保护已跟踪文件，扫描脚本也不证明所有敏感内容均已排除。
