# 海光 K100-AI 适配路线图

状态：理论方案，待实机验证。当前代码实现 CPU/CUDA 设备选择；K100-AI 的驱动、计算框架、算子、半精度和视频硬件解码能力均需按实际交付环境核实。

| 阶段 | 工作 | 验收依据 |
|---|---|---|
| 环境核对 | OS、驱动、厂商计算栈、匹配版PyTorch | 设备枚举、张量计算、显存分配正常 |
| 检测适配 | YOLO与torchvision NMS等算子 | 框坐标与检测召回回归 |
| 车辆特征 | FastReID与DINOv2 | 特征余弦偏差、排序、事件误报回归 |
| 人员辅助 | OSNet及可选人脸模块 | 独立人员样本与ID切换测试 |
| 多流性能 | 1路4K与其余1080P负载 | 延迟、吞吐、资源及持续稳定性 |

先尝试兼容框架直接推理；有不支持算子时，再评估替换算子或厂商支持的模型导出格式。模型转换和数值精度调整均需要重新做实例匹配回归。

CPU高负载优化方向包括限制线程池、减少全帧复制、筛选后再运行人脸、评估码流缓存和硬件视频解码。上述功能尚未全部实现，不能据此推断K100-AI实际吞吐。
